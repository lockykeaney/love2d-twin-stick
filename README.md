# The Binding of Smash TV

A top down shooter in the style of Binding of Issac and Smash TV.

I started this project as an opposite to my daily work, where everything is by AI agents. I don't learn anything new, I don't understand everything I do, there is no craft yet. I want to create something for me, and all by me.

My goal is to create a simple game that anyone can play for a few minutes and have fun. Run on browsers, or as a stand alone game. Play on steam deck.

I want anyone to be able to contribute and learn as well. Open Source game development.

The coding style will grow and change as I learn, but for now I want it as simple as possible, only adding libraries when absolutely neccassary.
